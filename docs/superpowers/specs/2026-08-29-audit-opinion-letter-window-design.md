# 의견서 강조사항 오탐 방지 설계

날짜: 2026-08-29  
상태: 초안 (브레인스토밍 승인 반영)  
범위: `packages/web-api` `classify_opinion` — 의견서 본문에서 거절·한정·부적정 키워드를
찾을 때 **강조사항·과거 보고서 인용**이 당기 의견으로 잡히지 않게 한다.  
선행: [2026-08-28 감사보고서 표지·의견 추출](2026-08-28-audit-opinion-extraction-design.md) §6.2·§7.

구현 계획이 아니라 **검색 구간, 인용 무시 규칙, 버전·재추출, 테스트 경계**다.

## 1. 문제

D-3-2는 compact 본문 **전체**에서 거절 키워드를 먼저 찾는다. 재발행 서식은 강조사항에
「YYYY년…일자로 발행한 감사보고서에서 의견을 표명하지 않았습니다」를 넣어, 당기가 적정이어도
`의견을표명하지않`에 걸려 `disclaimer`가 된다. 에코바이브 A001(20230718000294) 별도·연결이 그 예다.

당기 결론·근거 단락(`의견거절근거` 등)의 실제 거절·한정은 그대로 잡혀야 한다.

## 2. 전제

| 항목 | 결정 |
|------|------|
| 손대는 함수 | `classify_opinion`만. `resolve_opinion` 순위(의견서 > A001) 유지 |
| 키워드 목록 | D-3-2 `keyWord1..3` 유지. 짧은 `의견을표명하지않`을 목록에서 빼지 않음 |
| 적용 위치 | 자른 구간 안에서만 검색. 히트라도 과거 보고서 인용이면 그 위치는 버림 |
| 스키마 | `audit_report_facts` 컬럼·`conflicts` 타입 추가 없음 |
| A001 | 교차로 코드를 바꾸지 않음. 의견서 없고 A001만 있으면 지금과 같음 |
| GAAP·날짜 | 이번 밖. 날짜 전처리(`의견근거`~`재무제표에대한경`)와 섞지 않음 |

## 3. 분류 흐름

서식 판별(`looks_like_letter`)은 지금과 같다. False면 `not_found`.

True이면 compact 본문에 아래를 순서대로 적용한다.

### 3.1 검색 구간

compact 문자열에서 **끊는 표지**가 처음 나오는 위치 앞만 검색 구간이다.

끊는 표지(모두 compact 기준, 먼저 나온 것):

- `강조사항`
- `핵심감사사항`
- `기타사항`
- `재무제표에대한경`
- `감사의견에는영향을미치지않는사항`
- `영향을미치지않는사항`

에코바이브는 제목이 `강조사항`이 아니라 「감사의견에는 영향을 미치지 않는 사항」이므로
두 표지를 모두 둔다. `영향을미치지않는사항`이 더 짧아 앞에 매칭될 수 있다. 의도는 같다.

**자르지 않는 표지:** `감사의견근거`, `의견거절근거`, `한정의견근거`, `부적정의견근거`.
근거 단락의 D-3-2 키워드를 남기기 위함이다.

끊는 표지가 하나도 없으면 본문 전체를 구간으로 쓴다. 앞 N자로 자르지 않는다.

### 3.2 키워드

구간 안에서 거절 → 한정 → 부적정 순, 그룹 안 목록 순. 지금과 같다.

매칭마다 compact 기준 **앞 80자 + 키워드 + 뒤 80자**를 본다. 그 안에 아래가 있으면
그 히트는 버리고 같은 키워드의 다음 위치, 없으면 다음 키워드로 간다.

- `일자로발행한감사보고서에서`
- `비교표시목적으로`

채택한 히트의 `raw`는 그 키워드 문자열이다. 버린 히트는 `opinion_raw`에 넣지 않는다.
남은 히트가 없으면 `boilerplate_unqualified` / `unqualified`.

## 4. 버전과 재추출

`EXTRACTOR_VERSION`을 `audit_opinion.v2`로 올린다.

이미 `fetch_status=ok`인 행은 `extract`/`resume`이 건너뛴다. 오탐을 고치려면
`mode=reparse`로 의견 필드를 다시 뽑는다. override·LLM 날짜 보존은 기존 reparse 규칙을 따른다.

## 5. 테스트

live DART 없이 compact 가능한 한글 fixture.

| 케이스 | 기대 |
|--------|------|
| 적정 문단 + 강조사항/영향 없는 사항의 「일자로 발행한 감사보고서에서 의견을 표명하지 않았습니다」 | `unqualified` |
| 결론 또는 근거에 `의견을표명하지않습니다` 또는 `의견거절근거` | `disclaimer` |
| `한정의견근거단락에기술된사항이미치는영향을제외` | `qualified` |
| 끊는 표지 없음 + 거절 키워드 | `disclaimer` (전체 본문) |
| 기존 boilerplate·거절·한정·부적정·서식 아님 | 지금과 같음 |

## 6. 밖

- A001 당기 칸으로 의견서를 뒤집기
- 키워드 목록에서 짧은 `의견을표명하지않` 삭제
- `conflicts`에 오탐 기록
- 추출 잡·Admin UI 변경
