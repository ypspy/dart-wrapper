# 의견서 선행형·후행형 서식 분기 설계

날짜: 2026-08-29  
상태: 초안 (브레인스토밍 승인 반영)  
범위: `packages/web-api` `classify_opinion` — 2018년 감사기준서 700 개정
전·후 의견서 구조를 compact 본문으로 가른 뒤, 검색 구간만 다르게 둔다.  
선행: [2026-08-29 강조사항 오탐 방지](2026-08-29-audit-opinion-letter-window-design.md) (v2 구간·인용 무시).  
원전: 한공회 「2018년 감사보고서 작성사례」 별첨1·별첨2, 「감사보고서 작성사례 개정」(종전 보론).

구현 계획이 아니라 **서식 판별, 검색 구간, 키워드, 버전·재추출, 테스트 경계**다.

## 1. 문제

v2는 선행형(의견·근거가 앞, 그다음 KAM·강조사항)을 전제로 끊는 표지를 두었다.
`재무제표에대한경`이 종전 서식의 「연결재무제표에 대한 경영진의 책임」에 먼저 걸려,
영신 F002(`20170511002984`)의 `한정의견근거`가 창 밖으로 나가 `unqualified`가 되었다.

같은 v2는 에코바이브 A001(`20230718000294`) 강조사항 과거 거절 인용 오탐은 고친다.
종전 후행형과 2018 선행형을 **하나의 표지 목록**으로 자를 수 없다.

접수일·자산 2조 단계 적용만으로 서식을 가르지 않는다. KAM은 상장기업부터
단계 적용이고, 비상장 신 서식(별첨1 사례 1.3)은 KAM이 없다.

## 2. 전제

| 항목 | 결정 |
|------|------|
| 손대는 함수 | `classify_opinion`과 그 내부, `extract`/`resume`의 `_should_skip`. `resolve_opinion` 순위 유지 |
| LLM | 의견 분류에 쓰지 않음. 날짜 `ambiguous` 해소와 섞지 않음 |
| 키워드 목록 | D-3-2 `keyWord1..3` 유지. `의견을표명하지않`을 빼지 않음. 신 서식 제목 `한정의견`/`의견거절`을 키워드로 추가하지 않음 |
| 인용 무시 | v2와 동일. 구간 안에서 ±80자, `일자로발행한감사보고서에서` / `비교표시목적으로` |
| 스키마 | `audit_report_facts` 컬럼·`conflicts` 타입 추가 없음 |
| A001 | 교차로 의견 코드를 뒤집지 않음 |
| GAAP·날짜 | 이번 밖. 날짜 전처리의 `재무제표에대한경`은 **그대로** 둔다 |

전수 LLM은 의견서 leaf 약 44.9만 건 기준 `gpt-4o-mini` 중간안 일회 약 $1,350 수준으로
경제성은 있었으나, 규칙으로 서식을 가를 수 있어 채택하지 않는다.

## 3. 분류 흐름

`looks_like_letter`가 False이면 `not_found`. True이면 compact 본문에 아래를 순서대로 적용한다.

### 3.1 서식 판별

판별은 compact 문자열만 본다. `year_end`·접수일은 쓰지 않는다.

**선행형**이면 다음을 **위에서부터** 적용해 처음 맞는 것으로 정한다.

1. `재무제표감사에대한보고` 또는 `연결재무제표감사에대한보고`가 있다
2. `핵심감사사항`이 있다
3. `감사의견근거`가 있다 (`한정의견근거`와 다른 문자열이다. `한정의견근거`에 `감사의견근거`는 포함되지 않는다)

**후행형**은 위가 모두 아니고, `경영진의책임`이 있으며 그 **뒤**에
`한정의견근거` / `의견거절근거` / `부적정의견근거` 중 하나가 있을 때다.

어느 쪽도 아니면 **선행형**이다. 비상장 신 서식 한정은 KAM도 `감사의견근거`도 없을 수 있으나,
신 제목은 `경영진과지배기구의책임`이라 구제목 `경영진의책임` 부분문자열이 없어
후행형 조건이 성립하지 않는다.

구제목 `…경영진의책임`과 신 제목 `…경영진과지배기구의책임`을 같은 표지로 쓰지 않는다.

### 3.2 검색 구간

**선행형:** compact에서 끊는 표지가 처음 나오는 위치 앞만 검색한다. 표지(먼저 나온 것):

- `강조사항`
- `특기사항`
- `핵심감사사항`
- `기타사항`
- `계속기업관련중요한불확실성`
- `감사의견에는영향을미치지않는사항`
- `영향을미치지않는사항`
- `경영진과지배기구의책임`

`재무제표에대한경`과 짧은 `경영진의책임`은 선행형 표지가 아니다.

자르지 않는 문자열: `감사의견근거`, `의견거절근거`, `한정의견근거`, `부적정의견근거`,
신 서식 의견 제목 `감사의견` / `한정의견` / `부적정의견` / `의견거절`.

표지가 없으면 본문 전체다. 앞 N자로 자르지 않는다. 표지가 맨 앞이면 구간이 비어
`unqualified`가 되며, 본문 전체로 되돌리지 않는다.

**후행형:** 근거 표지(`한정의견근거` / `의견거절근거` / `부적정의견근거`)
**뒤**에 처음 나오는 `강조사항` / `특기사항` / `기타사항` 앞만 검색한다.
꼬리 표지가 없으면 본문 전체다. 앞 N자로 자르지 않는다.

### 3.3 키워드

구간 안에서 거절 → 한정 → 부적정 순, 그룹 안 목록 순. 인용 히트는 건너뛴다.
채택한 히트의 `raw`는 그 키워드다. 남은 히트가 없으면
`boilerplate_unqualified` / `unqualified`.

## 4. 버전과 재추출

`EXTRACTOR_VERSION`을 `audit_opinion.v3`로 올린다.

`extract`/`resume`은 `fetch_status=ok`이고 `extractor_version`이 현재
`EXTRACTOR_VERSION`과 같을 때만 건너뛴다. 버전이 다르면 다시 뽑는다.
`reparse`는 `not_found` 필드만 다시 뽑는다.
override·LLM 날짜 보존은 기존 reparse 규칙을 따른다.

## 5. 테스트

live DART·LLM 없이 compact 가능한 한글 fixture. 한공회 원문 파일은 저장하지 않는다.

| 케이스 | 기대 |
|--------|------|
| 종전: `경영진의책임` 뒤에 `한정의견근거` (영신형) | `qualified` |
| 종전 한정 + 강조사항·특기사항의 전기 거절 인용 | `qualified` (꼬리 창 밖) |
| 신 상장: `감사의견근거`·`핵심감사사항` 뒤 강조사항의 「일자로 발행한 감사보고서에서 의견을 표명하지 않았습니다」 (에코바이브형) | `unqualified` |
| 신 비상장: KAM 없음, 근거 다음 `경영진과지배기구의책임` | 근거 키워드는 창 안, 책임 단락은 창 밖 |
| 신 한정: `한정의견근거단락에기술된사항이미치는영향을제외` | `qualified` |
| 신 거절: 앞쪽 `의견을표명하지않습니다` | `disclaimer` |
| 기존 boilerplate·서식 아님·v2 인용 무시 회귀 | 지금과 같음 |

## 6. 밖

- 의견 분류 LLM
- A001 당기 칸으로 의견서를 뒤집기
- D-3-2에서 짧은 `의견을표명하지않` 삭제
- `conflicts`에 오탐 기록
- 내부회계 감사보고서
- 날짜 전처리 표지 변경
- Admin UI 변경
