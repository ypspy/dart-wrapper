# 정정 입수 섞임 점검

날짜: 2026-08-27  
상태: 승인됨 (실행)  
범위: `dart_catalog.db` A001 전량 + JW홀딩스 대조. **읽기 전용.**

## 목표

기재정정·첨부정정 행에 **다른 접수의 첨부**가 들어가 같은 문서가 두 번 쌓였는지 확인한다.

보지 않는 것: 첨부정정 엔트리의 `source` 표기(`body` vs `attachment`).

## 합격

1. 첨부 `viewer_url`의 `rcpNo` = 그 공시 `rcept_no`
2. 같은 회사·회계기간에서 한 `dcm_no`가 여러 `rcept_no`에 있으면 실패 후보
3. 기재정정 첨부가 같은 기간 **이전** 접수에도 있으면 실패
4. JW홀딩스(`00632304`) 7건 첨부가 설계 표와 일치

## 절차

1. DB 전량 쿼리
2. JW 7건은 DB와 스펙 비교 후 DART 재파싱
3. (1) 실패 시 해당 공시만 라이브 대조. 통과면 정정 많은 회사 2~3그룹만 확인
